# MacMD 0.1 — implementation plan and roadmap

Each step ended with `make lint test` green. The checked steps are done in v0.1.0.

- [x] **Scaffold**: XcodeGen `project.yml`, Makefile, `MacMDKit` package, AppKit lifecycle with NSDocument
- [x] **MacMDKit (TDD)**: SourceRangeMapper, SpanCollector, MathExtractor, Outline/Slugger, DocumentStats,
      ListContinuation, InlineFormatting, BlockFormatting, RelativePath, HTMLRenderer, robustness and performance tests
- [x] **Editor**: TextKit 2 view, async StyleEngine with block diffing, decorations, editing commands, status bar
- [x] **Reader**: WKWebView, `macmd://` scheme, CSP, theme CSS, vendored highlight.js/KaTeX/Mermaid, ⌘E position sync
- [x] **Sidebar**: outline with click-to-jump, lazy folder browser; focus and typewriter modes
- [x] **Export**: HTML (inlined CSS), PDF and print via an offscreen web view; Settings; app icon
- [x] **CI/CD**: lint + unit + UI tests on `macos-26`; tag-triggered DMG release with optional notarization
- [x] **Docs**: README, ARCHITECTURE, DESIGN, RELEASING, CLAUDE.md, project skills
